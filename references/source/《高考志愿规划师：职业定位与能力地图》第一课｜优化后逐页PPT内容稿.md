# 第二部分｜重新理解“高考志愿规划师”

## P07｜职业定义

### 标题

# 所以，什么是高考志愿规划师？

### 核心定义

> **高考志愿规划师，是基于学生特征、家庭诉求、成绩数据、院校专业信息与招生录取规则，帮助家庭建立决策逻辑，并最终形成科学志愿方案的专业服务者。**

### 五个核心关键词

# 学生

# 家庭

# 数据

# 规则

# 决策

### 页面收束

## P08｜职业边界

### 标题

# 规划师不是  
# “替别人做决定的人”

### 不是

替家长决定  
保证一定录取  
背大量学校资料  
背专业介绍  
帮客户填一张表  
依靠经验拍脑袋

### 而是

帮助家庭建立决策依据  
控制并解释录取风险  
理解院校选择逻辑  
判断专业与学生的匹配  
完成完整规划服务  
基于数据、规则和事实判断

### 页面核心

> **专业，不是替客户决定。**  
> **专业，是让客户知道为什么这样决定。**

# 第一课结束后，学员应该真正带走的三个答案

# 01

## 我要成为什么样的导师？

一个专业、负责、可信赖，能够独立解决真实家庭问题的高考志愿规划师。

# 02

## 我要具备哪些能力？

政策规则、数据分析、院校判断、专业理解、学生洞察、方案设计、沟通咨询、交付复盘。

# 03

## 接下来的60课时为什么要学？

因为每一节课程，都在帮助我从：

# “知道高考志愿”

一步一步走向：

# “能够独立完成一次专业服务”
