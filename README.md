# GEZHI NAVIGATOR PPT Skill 包

这是一个为 **GEZHI NAVIGATOR｜格知导师计划** 制作的长期复用 PPT Skill。

## 推荐使用方式

把整个文件夹/ZIP 交给支持 Agent Skills / 自定义 Skill 的工具。

主入口：

`SKILL.md`

如果平台不支持直接导入 ZIP：

1. 新建一个自定义 Skill；
2. 将 `SKILL.md` 作为核心指令；
3. 把 `references/` 下的规范文件作为知识/参考文件上传；
4. 把 `references/source/` 中第一课、第二课成品及内容稿作为参考附件；
5. 把 `assets/gezhi-logo.png` 作为品牌素材。

## 以后日常调用

通常只需要上传新课的 Markdown 内容稿，然后说：

> “调用 GEZHI NAVIGATOR PPT Designer，按内容稿生成完整可编辑 PPTX。”

如果内容稿已经写明 `GEZHI NAVIGATOR｜格知导师计划`，Skill 应直接开始，不重复问风格与颜色。

## 最重要的三条

1. 内容稿决定内容，不能擅自重写观点。
2. 第一课、第二课决定视觉体系，但不能死套页面。
3. 页面语义决定版式，必须完成信息设计，而不是文字搬家。
